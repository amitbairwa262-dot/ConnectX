Help & Support

OTP kahan milega?＋
Abhi SMS/Email service connect nahi hai, isliye OTP backend ke terminal (jaha uvicorn chal raha hai) me print hota hai.
Video/voice call me camera ya awaaz nahi aa rahi＋
Browser jab camera/microphone permission maange to Allow karo. Call ke liye dono users alag login hone chahiye (alag tab ya alag device) aur dono ka backend se connection chalu ho.
AI Assistant error de raha hai＋
AI features ke liye backend me ANTHROPIC_API_KEY environment variable set honi chahiye (sk-ant- se shuru hone wali key). Bina key ke baaki app normal chalta hai.
✓✓ (seen) kab dikhta hai?＋
Jab samne wala chat kholkar aapka message dekhe aur uska "Read receipts" setting on ho.
Status kitne der tak rehta hai?＋
24 ghante. Uske baad feed se apne aap hat jata hai. Apna status aap kabhi bhi delete kar sakte ho.
Group kaise banau?＋
Chats screen pe + dabao → "Naya Group Banao" → members chuno → naam do. Community ke andar group Communities tab se banta hai.
